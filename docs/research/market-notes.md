# Resource engine: running notes from examples (feeds the style guide)

## Listing / marketplace (TpT Linda Kamp plants unit)
- Complete unit (9 lessons, 12-day plan, assessment, key, notes) > loose sheets. US$12, 9.1k ratings.
- Same lesson anatomy every lesson. One signature make-and-display item (flower booklet). Display kit with lettering + photo.
- Square thumbnails: huge title + hero object; real photos of printed pages fanned on desk; unit colour frame; bottom banner with numeric claim; pill labels for components; one tile for the signature item.
- Listing text: intro para, bold headings, bullet lists of everything included. Alignment pages (her actual tags are loose: our edge).

## Teach Starter decks (place value, decimals, multiplication, angles, dialogue, explanation texts)
- I do / We do / You do icon key slide, then mode icon + coloured top bar on every slide.
- Fixed colour per place value across all visuals.
- Concept colour coding: each strategy/subtopic owns a colour used in its header bar and diagrams (multiplication deck).
- Rhythm per strategy: introduce, step-by-step worked (numbered steps left, built diagram right), "Show What You Know!" 4-option MCQ with correct answer highlighted on reveal, final "Choose your strategy".
- Activity slide then Answers slide. "Let's check" then reveal.
- Definition box with bold coloured key term.
- Example vs non-example with tick/cross.
- STOP "use reasoning" sanity-check slide.
- Turn and Talk with 30-second timer graphic. Think -> Talk -> Write cycle on one real photo, then model answer with "Writer's Tip".
- Interactive "Your turn" slides with a typing box per photo.
- Annotated model text with colour-coded language features + legend (English).
- Reflection slide with sentence starters ("I know... because...").
- Independent task slides link to other products (cross-sell).
- Weak points to beat: dated clip art, tiny dense text, rule-based rounding, "units", no LI/SC or differentiation, no notes.

## Mathletics Series D (student + teacher books)
- Page anatomy: title line, rounded teaching box with worked example, numbered circle questions with a/b/c/d parts, dotted dividers, footer series/topic badge + page number.
- Black and white by default.
- Teacher book = student pages with answers overlaid in grey handwriting font; "Answers will vary", "Teacher check".
- Assessment pages end with skills table: Not yet / Kind of / Got it.
- Page types: practice; apply / solve / investigate (Getting ready, What to do); games with "copy" icon.
- Contents page with date-completed column. Outcomes mapping page at end.
- Character "Remember" tips, sparingly.

- Word wall explicitly sells "Canadian, Australian & UK spellings" -> Australian spelling is a recognised buyer need.
- Clean modern sellers (Jillian Starr, Create Teach Share, My Nerdy Teacher) use white/bright photos, pastel brights, bold sans; dated sellers use clip art and chalkboards and still sell on volume of reviews.

## Australian competitor: The Busy Honey Bee (thebusyhoneybee.com.au, NSW, Shopify + TpT), checked 19 Oct 2026
- 2,417 products (342 created 2023, 751 2024, 1,137 2025). Types: Teaching Slides 560 (median A$9, unit A$12.99, term mega bundle ~A$56), Assessments 498 (median A$4.50, unit A$6.50, year bundle A$135), Warm-up/Revision 437, Activity Packs 310, Worksheets 275, Homework/Casual 172, Teaching Bundles 143. Only 8 free.
- Model: one product per NSW DoE sample unit (e.g. "Stage 2 Year A NSW Maths Unit 15"), sold 5+ ways (slides, assessment, warm-ups, worksheets, homework), term + year bundles, multi-teacher licences, points, newsletter. 253 site reviews ~91% 5 star, "14k+ teachers".
- Slides: complement DoE sample units, attribute © State of NSW, "not endorsed". Cannot include DoE resources (copyright) so slides prompt teacher to insert them = prep gap.
- Slides choose 3 themes (Brights, Calm, Honey Bee). Font: Edu NSW ACT Foundation (Google, school handwriting font). Header bar: Lesson N pill, title, Resource N, I do/We do/You do tag. Real photos (Australian banknotes), teacher cut-out photo, Turn and Talk, drag-and-drop digital manipulatives (counters, MAB) in edit mode, game links, simplified unit of work, LI/SC per lesson.
- Assessments: 3 columns below / at / above stage, editable Word + PDF + answer key; wombat/kangaroo icons mark ES1/S1 in multi-age.
- Gaps vs us: worksheets and differentiation are separate purchases, not in each lesson; teacher must insert DoE resources; busy pastel design with many display fonts; no research/teacher guide.
